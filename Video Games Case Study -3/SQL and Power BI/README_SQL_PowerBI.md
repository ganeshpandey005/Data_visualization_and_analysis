# SQL & Power BI – Video Game Sales Analysis

## 📌 Project Overview

This project focuses on analyzing video game sales data using **SQL and Microsoft Power BI**.

The business case is based on **Sony Interactive Entertainment (SIE)**, with the objective of performing competitor analysis and understanding regional and global video game sales trends across different gaming platforms. The analysis uses four related datasets covering genres, platforms, publishers, and game sales.

## 🎯 Business Objective

The objective of this project is to analyze the video game industry and derive meaningful insights related to:

- Video game sales across different regions
- Gaming platforms
- Game genres
- Game publishers
- Regional and global sales trends
- Publisher performance and competitive analysis

## 📂 Datasets

The project contains four datasets:

1. `video_game_genres.csv`
2. `video_game_platforms.csv`
3. `video_game_publishers.csv`
4. `video_game_sales.csv`

### Data Dictionary

#### `video_game_genres.csv`
- **Genre ID** – Unique ID of each game genre
- **Genre** – Name of each game genre

#### `video_game_platforms.csv`
- **Platform ID** – Unique ID of each gaming platform
- **Platform** – Name of each gaming platform type

#### `video_game_publishers.csv`
- **Publisher ID** – Unique ID of each game publisher
- **Publisher** – Name of each game publisher

#### `video_game_sales.csv`
- **Game Name** – Unique name of the game
- **Publish Year** – Year that the game was released
- **Platform ID** – ID of the platform that the game was released on
- **Genre ID** – ID of the game genre
- **Publisher ID** – ID of the game publisher
- **NA_Sales** – Total sales in North America
- **EU_Sales** – Total sales in Europe
- **JP_Sales** – Total sales in Japan
- **Other_Sales** – Total sales in other regions

## 🗄️ SQL Analysis

SQL was used to work with the relational datasets and perform data analysis.

The SQL part of the project focuses on:

- Working with multiple related datasets
- Joining sales data with publisher, platform, and genre information
- Analyzing regional sales
- Analyzing publisher performance
- Analyzing platform performance
- Analyzing genre performance
- Aggregating sales data
- Identifying useful business insights from the data

## 📊 Power BI Analysis

Power BI was used to transform the analyzed data into an interactive business intelligence report.

The Power BI analysis focuses on:

- Regional sales analysis
- Publisher-wise sales analysis
- Platform-wise sales analysis
- Genre-wise sales analysis
- Global sales trends
- Interactive visualizations and dashboards

## 📈 Dashboard & Visualization

The Power BI report provides visual analysis of the video game industry data and helps understand:

- Which publishers contribute to sales
- How sales vary across regions
- How different platforms perform
- How different genres perform
- Overall sales patterns and trends
