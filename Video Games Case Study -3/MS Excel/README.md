# Video Game Publisher Analysis – Excel Project

## 📌 Project Overview

This project is an **Excel-based data analysis project** focused on video game publishers, their sales performance, best-selling games, and overall contribution to the video game industry.

The dataset contains information related to **video game sales, publishers, platforms, and genres**. The project uses Excel formulas, Pivot Tables, filtering, sorting, and charts to answer business questions and identify leading publishers.

## 🎯 Business Objective

The main objective is to analyze video game sales data and:

- Identify the **Top 5 video game publishers** based on total global sales.
- Calculate and compare publisher-wise total sales.
- Identify the publisher with the **highest number of best-selling games** (games with sales above 10 million).
- Calculate each publisher's **percentage contribution to total industry sales**.
- Present the analysis using **Pivot Tables and charts**.

## 📂 Dataset / Worksheets

The Excel workbook contains the following sheets:

- `video_game_sales` – Video game sales data.
- `video_game_publishers` – Publisher-related information.
- `video_game_platforms` – Gaming platform information.
- `video_game_genres` – Game genre information.
- `Questions` – Business questions and project requirements.
- `Q3` – Pivot Table solution for publisher-wise total sales.
- `Q4` – Analysis of publishers with the highest number of best-selling games.
- `Q5` – Publisher contribution to total industry sales and related Pivot Chart.

## 🔍 Analysis Performed

### 1. Missing Data
Missing columns in the sales, publishers, and platforms data were updated using the information available in the other worksheets.

### 2. Top 5 Publishers
Publishers were ranked according to **Total Global Sales**.

The calculation used:

`Total Global Sales = NA_Sales + EU_Sales + JP_Sales + Other_Sales`

The Top 5 publisher records were highlighted in the summary table.

### 3. Publisher-wise Sales
A Pivot Table was created to calculate total sales for each publisher.

### 4. Best-Selling Games
Games with **more than 10 million sales** were considered best-selling games.

The publisher having the highest number of such games was identified.

### 5. Industry Sales Contribution
A Pivot Table was created to calculate each publisher's percentage contribution to total industry sales.

A suitable Pivot Chart was created to visualize the contribution.
