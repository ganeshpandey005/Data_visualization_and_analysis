# Consumer Complaints Data Analysis

## 📊 Project Overview
An **Excel Data Analytics project** based on consumer complaint data. The project covers data cleaning, analysis, reporting, KPI calculation and dashboard creation.

## 🔍 Key Analysis

- State-wise complaint and missing State Name analysis
- Complaint resolution time calculation
- Year and US Fiscal Year Quarter creation
- Company-wise complaint analysis
- Timely response and disputed complaint analysis
- Average complaint closure time
- Top 5 companies by complaint volume
- Top 5 complaint issues
- Monthly complaint trend analysis
- Product-wise and channel-wise complaint distribution
- KPI and YoY analysis
- Complaint prioritization dashboard

## 🛠️ Tools & Skills
- Microsoft Excel
- Data Cleaning & Transformation
- Pivot Tables & Excel Formulas
- KPI Analysis
- Trend Analysis
- Data Visualization
- Dashboard Creation

## 📌 Project Outcome
Converted raw consumer complaint data into **structured reports and a management dashboard** to identify complaint trends, major issues, company-level performance and areas requiring attention.

**Project Type:** Data Analytics | Excel | Business Intelligence
